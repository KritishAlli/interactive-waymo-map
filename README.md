# Waymo Fare Calculator

**Live site: [waymofares.org](https://www.waymofares.org/)**

A free, unofficial Waymo fare estimator and service area map. Search an address to see
whether it's inside a Waymo service area (and how far away it is if not), or plan a
pickup → dropoff trip to estimate the fare. Covers San Francisco, Los Angeles, San Diego,
Phoenix and Dallas.

Not affiliated with Waymo.
